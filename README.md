# 👋 A Little About Me

I'm **Kani**, a final-year **B.E. Computer Science and Engineering** student at **Government College of Engineering, Tirunelveli, Tamil Nadu**.

Although my degree is in Computer Science, the part of computing that has always interested me most is the **problem-solving side** — especially mathematics, patterns, probability, statistics, and understanding how an idea can be turned into a working system.

That interest has gradually shaped the direction I'm taking:

**Mathematics & Statistics → Data → Machine Learning → Intelligent Systems**

I'm currently building my skills around **AI/ML, Data Science, NLP/LLMs, Data Engineering, and MLOps**, while trying to understand the reasoning behind the systems I build rather than simply using libraries and frameworks.
